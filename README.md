Eco-Friendly Environment Passion Project

## Project Showcase Prep

 I chose this topic for my project because I wanted to create something that would make sustainability easy. Using HTML, CSS, and JS, this MLM can differentiate between objects that can be recyclable or not. This model is still in training to include a more diverse range of objects. 
 

To use, simply lift an object to the camera, and it will tell you if it is eco-friendly or not. Due to issues with CodeSandbox, this model can be accessable with this preview link: https://42nqr7.csb.app/
